# Magic 8 Ball

A fun Magic 8 Ball website that gives you quirky yes/no answers with a themed twist!

This is my very first JavaScript project, built using **HTML**, **CSS**, and **vanilla JavaScript**. Users can ask a question, click the ball, and get a random response based on a selected theme. Themes so far include Moira Rose (Schitt’s Creek), Greg Davies (Taskmaster) and Lorelai Gilmore (Gilmore Girls).

## Live Site

You can view the deployed site here: [anaherawashere.github.io/magic-8-ball](https://anaherawashere.github.io/magic-8-ball/)

## Tech Stack

- HTML5
- CSS3
- JavaScript (no libraries or frameworks)

## Getting Started

To run locally:

1. Open the folder in VS Code
2. Install the Live Server extension
3. Right-click index.html → Open with Live Server
4. Your project will run at something like http://127.0.0.1:5500/
